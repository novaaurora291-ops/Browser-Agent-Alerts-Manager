# Hark Browser Manager

Windows desktop app (Python + PySide6) that manages **Cent Browser** profiles (each with its own `--user-data-dir`) and alerts you when a Hark agent is waiting for your reply. Google Chrome, Edge and Brave are never scanned, matched, launched or touched: a window counts only when its process is the configured Cent `chrome.exe` (full path) running one of the managed profiles' data folders.

## Features
- **Profiles**: every managed Cent profile with name, live preview and status (Needs reply / Working / Idle / Closed). Add Profile, Search, Status filter, Grid/List, Launch, Focus Window (brings that profile's existing window forward).
- **Alerts**: a small bridge extension (in `extension/`) watches hark.com tabs, including background tabs. Each new Hark question gives one desktop notification and one Telegram message with the profile name and the exact question. Open Task opens the right Hark conversation in the right profile. An alert turns Resolved once you reply in Hark. Alerts are keyed by the Hark message id, so restarts never repeat them.
- **Settings**: preview refresh, start with Windows, minimize to tray, notifications, Telegram bot token (stored in Windows Credential Manager, never in files or logs) and Chat ID, optional proxy for Telegram only (Proxy type Auto / HTTP/HTTPS / SOCKS5; accepts `IP:PORT:USERNAME:PASSWORD`, `user:pass@host:port` or `socks5://` / `http://` URLs; kept in Credential Manager and masked in logs), Send test alert (runs getMe, then a test message).
- **Shared Repo Team** (Settings > Shared Repo Team, or Team Dispatch > Edit team): one local git repo, one base commit, a Planner (ChatGPT) profile and worker profiles, each with an `@alias` and its exact `https://hark.com/project/<id>` URL. Saving creates (or reuses) one git worktree + branch per worker (`agent-<alias>`, from the same base SHA; git runs with argument lists, no shell). The Profiles grid links the team's cards with lime lines to a `Repo: <name> (N Linked • Worktrees Ready)` badge. Multi-View never switches the Planner's tab.
- **Team Plan & Safe Dispatch** (right panel drawer): paste the ChatGPT plan; `@alias` blocks are parsed (unknown, duplicate and empty blocks are flagged) and every worker card shows its project, branch, worktree and the full final prompt (worktree path, branch and base SHA come first). Dispatch re-verifies right then: worktree (repo, path, branch, clean, not busy) and the exact active project tab of that authenticated profile with a ready, empty composer. Only verified workers get the prompt; "Sent" shows only when the new user message appears in the page, otherwise "Unconfirmed" (never re-sent). Each send has an expiring dispatch ID and is refused if repeated.

Telegram calls use a small built-in HTTPS client that splits the TLS ClientHello, which gets through networks that reset connections to api.telegram.org.

## Run from source
```
pip install -r requirements.txt
python run.py
```
## Build the EXE
```
pip install pyinstaller
build.bat
```
Output: `dist\HarkBrowserManager.exe`.

## Bridge extension
Profiles page > profile menu > Install bridge (loads the profile's own copy of `extension/` unpacked through chrome://extensions, Developer mode). It only talks to `127.0.0.1:47823`. No cookies are read. Every request carries the profile's managed ID and its own secret token (generated by the Manager, kept in Windows Credential Manager and in that profile's `_hbm_bridge/tag.json`); anything else is refused. Running bridges reload themselves when their files differ from the Manager's (extension version `1.0.17`, equal to `core.EXT_VERSION`).
